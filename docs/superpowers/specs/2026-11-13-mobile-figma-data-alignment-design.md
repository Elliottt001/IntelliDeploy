## 3. 采用的推进方式

采用“数据契约→源组件能力→逐页实现”的增量方式。数据契约先解决四个详情错误和帖子查询，随后页面使用真实DTO；源组件能力统一处理重复的几何、文字、效果和实例覆盖，再逐页确认完整属性及交互。

另外两种可行方式是先完成页面再补数据接口，或同时重写数据/页面/渲染层。前者会继续依赖替代内容并返工，后者修改面和回归定位成本更大。当前已有组件、源提取器和API客户端，因此不另建路由树、通用页面引擎或第二套业务客户端。

## 4. 数据契约：外部资源和托管应用

### 4.1 判别与兼容

在后端集中判别资源类型。只有持久版本同时声明`source_mode=external_reference`和`deployment_managed=false`时，判为EXTERNAL_REFERENCE；其余按已有托管流程处理。不得按ID前缀、名称、域名或特殊stop_reason自行推断类型。

对AppSummary和PublicationResponse添加兼容字段：

- `resource_kind: HOSTED | EXTERNAL_REFERENCE`，现有正常托管记录默认HOSTED。
- `external_url: string | null`，仅外部资源使用，优先读取对应instance.url，缺失时读取同一持久version.delivery.url；两者同时存在却不一致时不输出入口，记录来源不一致。校验为允许的HTTP(S)链接，拒绝带凭据或非HTTP(S)协议的值。
- PublicationResponse添加`can_copy: boolean`，基于资源类型及既有版本验证/构建产物条件；默认保留正常托管应用当前能力。

外部资源的`available`不因外部地址存在而改为true，`url`仍保留托管入口含义。不能把外部站点、源码仓库或下载地址包装成平台验证报告、单次登录callback或部署成功证据。

### 4.2 应用详情的结果

对EXTERNAL_REFERENCE，AppDetail返回已有真实对话/Job、明确的resource_kind/external_url，`instance=null`、`delivery=null`。AppSummary的`instance_status=null`，避免把非托管外部资源呈现为用户可恢复的STOPPED实例。既有底层数据库记录保留，审计分类不改写其状态或内容。

因此外部详情不会把非托管stop_reason送入InstanceSnapshot，也不会把external版本的URL/源码字段送入平台DeliveryResult。HOSTED继续使用原有instance/delivery验证。不得为消除错误而扩大所有托管停止原因枚举、忽略Pydantic错误或伪造RUNNING/SUCCEEDED。

四个外部资源可在已设计的商店/产品列表中展示真实名称和摘要，提供明确的“打开外部资源”能力。对于已存在但VISUAL_PENDING的详情页面，仅增加该功能分支及托管操作防护，不重做布局。外部打开不调用issueLoginCode，不发送平台token，不调用托管使用接口制造消耗记录。

外部资源的复制请求在后端明确拒绝，并返回现有风格的409业务错误；前端基于can_copy隐藏或禁用不支持的复制操作。拒绝发生在解析外部validation为托管ValidationReport之前。

既有实例操作和身份code端点也使用同一后端资源判别，拒绝对EXTERNAL_REFERENCE执行start/stop/delete或签发托管身份，拒绝发生在预留额度和执行副作用之前，不能仅靠前端隐藏按钮。外部详情不允许发送调整请求或resume来改写外部记录；前端可保留草稿但禁用托管提交，后端明确返回409。后续若要从外部源码创建新应用，仍使用已有创建入口和独立App/Job，不复用当前外部记录冒充托管任务。

### 源属性

每个状态分别记录STRUCTURE、GEOMETRY、TEXT_STYLE、PAINT_EFFECT、INTERACTION和DATA_BINDING结果。不得将它们合成一个无法定位的“页面看起来一致”。完整严格通过需要所有适用项通过；NOT_IMPLEMENTED/NOT_RUN/缺真实数据字段准确保留。

源测试既核对输入源及提取结果，也核对实际运行时组件/DOM属性；不能用“源码包含同样常量”的自证测试替代运行时验证。375尺寸按源数据，320/430尺寸按明确约束验证，不整体缩放、裁掉长回复或缩小点击目标。

不更改原Figma参考、旧pixel比较器、mask、阈值或批准缺失基线。用户本轮要求的数据属性验收是额外证据，不能把旧10PASS/16FAIL自动改为26PASS。若以后运行图像回归，它仅用于验收记录，不用于开发推测。

执行相关后端协议/集成测试、共享客户端生成/构建、前端单测/typecheck、源属性与功能E2E、持久跨端E2E及三平台export。外部网络/模型/支付和iOS/Android设备缺条件时保持NOT_RUN；export不计设备启动或效果支持通过。
