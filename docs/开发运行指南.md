## 1. 环境与数据库

使用Python3.13、Node24、npm及Docker/Compose。本机已建立.venv和带持久卷的独立PostgreSQL17；新环境执行：

```bash
uv python install 3.13
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python -r backend/requirements.txt -r backend/requirements-dev.txt
docker compose -p intellideploy-dev -f infra/compose.dev.yml up -d --wait postgres
```

数据库端口127.0.0.1:55432；开发库intellideploy_dev，测试库intellideploy_test。初始化脚本仅在新卷第一次启动时创建测试库；已有卷可检查后执行createdb，不删卷重建。

从backend/.env.example创建backend/.env，设置随机SECRET_KEY和实际所需配置。保留本地dev/test数据库地址，真实配置不提交。配置从backend/.env绝对路径读取；测试只接受专用intellideploy_test，禁止使用生产库。旧backend/intellideploy.db保留，不迁移或清空它。

正式API启动只核对迁移，不自动create_all。模型、云及支付缺配置不影响OpenAPI导出，但对应真实验收为NOT_RUN。

根package-lock管理frontend、web和packages/api-client；两客户端保留各自React/框架版本。Worklets按原Expo锁文件固定兼容版本，不使用force忽略peer冲突。

```bash

npm --workspace @intellideploy/api-client test

```

api:generate导出后端OpenAPI、生成TypeScript类型并构建ESM请求包。后端协议改变后重新执行；不要手改generated.ts。共享包当前覆盖01应用/任务/报告/下载和06额度接口，实例、能力、社区与额度方法随对应后端任务接入后扩充。

## 3. 启动入口

在web/.env.local设置：

```dotenv
API_BASE_URL=http://127.0.0.1:9000
WEB_ORIGIN=http://localhost:3000
SESSION_SECRET=替换为至少32字符的随机秘密
```

SESSION_SECRET只在Web服务器使用；浏览器会话是加密、HttpOnly cookie。生产配置HTTPS的WEB_ORIGIN，cookie为Secure。修改请求必须同源；BFF不允许浏览器选择任意上游URL。

四个终端分别运行：

```bash
npm run dev:api
npm run dev:worker
npm run dev:web
npm run dev:mobile
```

dev:api提供持久状态、社区/副本、能力与实例API；dev:web提供工作台/社区SSR与BFF。dev:worker已加载候选验证/发布与维护循环；默认新生成/调整的需求冻结和generate_candidate仍需P7接线，COPY已有固定来源分支，受控runner/实例数据库与配置、真实目标未准备时不会模拟成功。Expo创建/应用列表/对话页已切换到新接口，可查看同一持久任务、取消、补额度恢复及离开后回读；完整真实生成需P7接线及受控外部资源。

浏览器API文档：http://localhost:9000/docs；Web地址：http://localhost:3000。Swagger注册/登录使用JSON，Authorize填Bearer token。POST /api/apps需Idempotency-Key，取得app_id/job_id后轮询GET /api/jobs/{id}。当前可验证持久化、归属、幂等、对话、取消和事件；没有生成引擎不能等待它自动交付。

WebBFF的/api/auth/login映射后端/auth/login，登录返回不含token；后续同源请求通过cookie认证。API/Expo直接使用/auth/login和Bearer。登录POST需正确Origin。

## 4. 手机与验证边界

手机EXPO_PUBLIC_API_BASE_URL需设为电脑局域网地址，例如http://192.168.1.10:9000；真机localhost是手机自身。Android标准模拟器可用http://10.0.2.2:9000，其他模拟器按网络配置；iOS模拟器通常可访问本机localhost。API监听0.0.0.0，系统防火墙需允许开发连接。生产使用HTTPS；浏览器预览额外来源需登记CORS_ORIGINS。

Expo55已支持npm工作区解析，沿用现有Metro/NativeWind配置；共享包先构建dist。原生端使用SecureStore；启动时迁移旧AsyncStorage token，成功后删除旧值，退出清理两者。Expo浏览器预览使用独立AsyncStorage适配。前台每3秒串行轮询，后台取消读取并停止timer；回到前台立即回读，网络失败退避至30秒。草稿、原请求键和最近app_id按账号保存，登录过期返回原应用。

应用标识为iOS bundleIdentifier / Android package：`cn.elliotttzhang.intellideploy`。已执行Web/iOS/Android导出；原生开发构建、SecureStore设备实测和原生UI流程尚未执行，不能用导出代替。当前Expo CLI提示既有react-native、react-native-svg、worklets版本与建议值有差异；依赖锁保持现有兼容约定，原生构建前核对并以设备结果记录。

```bash
npm --workspace frontend run typecheck
npm --workspace frontend test
npm --workspace frontend exec -- expo export --platform all --output-dir .expo/phase1-export
npm --workspace frontend run test:e2e
npm --workspace frontend exec -- expo run:ios
npm --workspace frontend exec -- expo run:android
```

`test:e2e`先启动9105 API（仅intellideploy_test）、3105 Next生产模式服务及8085 Expo浏览器预览；相应端口应空闲。浏览器覆盖协议夹具和真实PG/API跨端续接，追问状态由测试夹具设置，报告保留NOT_RUN。不能与会清理同一测试库的pytest同时运行。Preview CI使用仓库变量`INTELLIDEPLOY_PREVIEW_API_BASE_URL`指定实际HTTPS测试API；留空仅能本地预览，不能声称在线联调。完整原生记录见[原生客户端验收记录](原生客户端验收记录.md)。

代码隔离执行/BuildKit、Linux/Sealos目标和TLS按外部清单登记后由对应任务接入；不能在本机API容器挂宿主Docker socket代替隔离节点。真实生成、两云、三支付和原生验收另保存证据，不把状态fixture或构建通过当成一期完成。


## 5. 第8步社区、实例及应用登录

Web社区为`/community`、`/community/{publication_id}`；我的应用按创建/副本/最近使用/收藏查看。Expo同样使用`/community`与`/community/{id}`，最近使用/收藏位于`/library/recent`与`/library/favorites`。公开页可匿名读取，个人额度、收藏和副本按需登录。

拥有者在应用页配置VISITOR或SPONSOR及DAY/MONTH赞助上限。POST apps/{id}/publish只发布当前已验证运行版本；取消公开不删除实例。成功调整同步公开版本，既有副本固定来源。实例操作返回独立operation_id，客户端轮询终态再回读；删除需输入DELETE并明确delete_data，停止保留数据。

D脚手架使用`/api/platform/callback`交换单次code，应用服务端设置HttpOnly cookie并跳转无code地址；Proxy每次请求调用实例access授权，取消公开立即拒绝新的访客请求。需要实例配置`PLATFORM_CAPABILITY_URL`、`PLATFORM_INSTANCE_ID`、`PLATFORM_INSTANCE_TOKEN`、`PLATFORM_LOGIN_CALLBACK`；这些配置由受控部署接线提供，不能复制源实例凭据。应用业务路由使用lib/platform/session的requireAppUser获得经平台验证的用户身份，并将app身份传入能力调用。A/B/C保留原仓库账号/运行栈并执行对应接入验收。

真实集成检查仍NOT_RUN。Web/Expo浏览器夹具及跨端Publication/COPY状态检查仅证明本地协议与页面行为，不是云副本、真实AI/Search或原生设备证据。


## P7默认Worker接线（2026-11-11）

默认run_pipeline已自动组装JobExecution、受控runner、候选身份/数据库与发布适配；先核对配置/目标，保存需求/用量/检查点，随后执行现有生成循环。配置不完整会保存TARGET_UNAVAILABLE而非永久RUNNING；WAITING_USER回答仍续接同job，PAUSED_QUOTA按新父预留继续，未知外部动作不盲目重放。

backend/.env.example新增RUNNER_URL（HTTPS）、CA/CERT/KEY文件、RUNNER_RPC_TOKEN、PLATFORM_CAPABILITY_URL、APP_IDENTITY密钥、实例数据库及模型/价格限制。节点启动和mTLS/私有配置见infra/executor/README.md。部署目标capacity需登记gateway_image固定digest；Linux持有实例范围secret文件，K8s使用实例Secret，通用入口对每次请求验证平台身份/可见性并清除伪造用户头。源码与镜像不含这些值。

使用外部PostgreSQL需INSTANCE_DATABASE_ADMIN_URL及实例可达HOST，准备pg_dump/pg_restore；或为新应用配置固定INSTANCE_POSTGRES_IMAGE作为独立伴生服务。无法证明旧数据迁移安全时拒绝自动发布。用户原生/真实数据验收、节点网络/配额和两云演练仍NOT_RUN。

原生脚本ios/android使用expo run命令；生成ios/android目录由Expo prebuild重建并被Git忽略。Worklets统一固定0.7.4以匹配Reanimated4.2.1。iOS缺Simulator.app且原生依赖下载未成功，Android React Native AAR下载超时，当前不能宣称原生客户端验收通过。
