Building the Electron App
Commands required to build the app on Windows, Linux and macOS (untested) are npm run build:win, npm run build:linux and npm run build:mac respectively.
| Windows | Linux | MacOS |
| npm run build:win | npm run build:linux | npm run build:mac |
Navigate to Electron\zenshin-electron.
Run npm i or npm install
Run npm run build:win
Check the dist folder (Electron\zenshin-electron\dist), zenshin-electron-x.x.x-setup.exe is the setup and the folder win-unpacked contains pre-installed / unpacked files.
Zenshin.exe inside the win-unpacked folder (dist\win-unpacked\Zenshin.exe) can be used if you want to avoid installing the setup.
Example : YouTube: Building on Ubuntu. Same process can be followed for other Operating Systems with their respective build commands.
