# Prompt: mainHomeMotion.ts

## Responsibility

Store motion constants and helpers for the mobile main UI.

## Inputs

- Figma prototype transition values
- React Native `Animated` and `Easing`

## Output

- Duration constants
- Easing helpers
- Intro stagger metadata

## Rules

- Match Figma durations where known.
- Keep animation configuration out of visual components where practical.
